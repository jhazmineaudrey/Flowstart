# Flowstart
Flowstart is a website built with a timer based off of the "Flowtime Technique" designed to help you focus and get started with your tasks; solely developed by Jazz.

## Features
Flowstart has the following features:

**I. Flowmodoro Timer**
- Based off of the "Flowtime Technique", the flowmodoro timer adjusts according to the amount of time you've worked for (with an initial addition of 5 minutes to break resistance). 
  - You start the timer, with a 5 minute countdown to help you start your task.
  - After that initial 5 minutes, you get to decide whether to continue or stop if you are still feeling burnt out.
  - If you choose to continue, the timer will act as a stopwatch, where you can work until you feel like you're getting distracted or you need a break.
  - The timer will then calculate the amount of rest time you should take depending on how long you worked for.

**II. Task List**
- Allow the user to add their tasks
  - The user can then specify what task they would like to work on during their focus time.
- The tasks created by the user will also be saved in their local browser. (Cross-device saving will be added in the future)

**Planned Features**
Below are features that I plan to add in the future:
- A custom music player for you to play music/sounds in the background
- A page for the user to view their stats over a set amount of days
- Integration with Todoist (and/or other popular task managers) where you would be able to import your tasks
